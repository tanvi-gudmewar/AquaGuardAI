# Frontend setup — HTML, CSS, JavaScript and React

1. Install Node.js 20 or newer.
2. Open a terminal in `frontend/`.
3. Run `npm install`.
4. Copy `.env.example` to `.env` if you need a custom backend URL.
5. Run `npm run dev`.
6. Open the Vite URL, usually `http://localhost:5173`.

Files:
- `index.html`: HTML document entry point.
- `src/main.jsx`: React entry point.
- `src/App.jsx`: page layout and interactions.
- `src/styles.css`: responsive CSS.
- `src/api.js`: JavaScript API calls to Spring Boot.

The UI uses React components written in JavaScript (JSX), ordinary CSS, and an HTML entry file. It does not use TypeScript.
